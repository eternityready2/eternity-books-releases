# Eternity Books Premier

Download the latest version from [Releases](https://github.com/eternityready2/eternity-books-releases/releases/latest):

- **Windows 10/11:** `EternityBooks-Setup-<version>.exe` - run it. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.
- **Linux (Ubuntu 22.04+, Linux Mint 21+, Debian 12+, Pop!_OS):** `eternitybooks_<version>_amd64.deb` - double-click it to open in Software Install, or run `sudo apt install ./eternitybooks_*_amd64.deb`.

Installed copies update themselves (Help > Check for Updates, or automatically once a day).
Your books are stored on your own computer and are never part of the download.
